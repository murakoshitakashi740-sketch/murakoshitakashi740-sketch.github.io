Política de privacidad

Esta aplicación la usa únicamente el propietario del canal «Fama Sombria» para leer los datos de su propio canal de YouTube mediante la API de YouTube (YouTube Data API y YouTube Analytics API) con los permisos de solo lectura de vídeos, analíticas e ingresos, y el permiso necesario para descargar los subtítulos de sus propios vídeos.

Qué datos se leen: títulos, descripciones, miniaturas, estadísticas, curvas de retención, ingresos estimados y comentarios del canal conectado. Dónde se guardan: solo en el ordenador del propietario. Con quién se comparten: con nadie; no se venden ni se ceden. Cuánto tiempo: mientras el propietario use la herramienta; puede borrarlos en cualquier momento.

El acceso se puede revocar en myaccount.google.com/permissions. El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Contacto: el propietario del canal, por el correo de la cuenta de Google del canal.
